# Core runtime dependencies for the SoCal wildfire / grid co-simulation.
#
# Version selection rationale (Aug 2026):
# - palaestrAI 3.5.11 pins numpy~=1.26.4 and pandas~=2.1.4.
# - pandapower 3.2+ requires numpy>=2 and pandas>=2.2 (3.4.0 requires
#   pandas~=2.3), which breaks the palaestrAI numpy/pandas pins. The newest
#   pandapower that still permits pandas 2.1.4 and numpy 1.26.x is 3.1.2.
# - simbench 1.6.2 requires pandapower>=3.4.0 (transitively pulls pandas 2.3),
#   so it also breaks the stack. simbench 1.6.1 works.
# - midas-powergrid 2.1.1 has no upper pin on numpy/pandas/pandapower, so it
#   inherits whatever pip resolves from the pins below. No --no-deps hack
#   is needed as long as this file is installed with pip's real resolver.
#
# Do not bump numpy, pandas, pandapower, or simbench without re-validating.
numpy==1.26.4
pandas==2.1.4
scipy>=1.11,<2
pandapower==3.1.2
networkx>=3.0
matplotlib>=3.7
