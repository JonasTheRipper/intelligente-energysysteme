# v0.5 — Perimeter Calibration & Validation (Eaton + Palisades)

v0.5 grounds the testbed in the **real January 2025 SoCal fires**. Both the **Eaton**
and **Palisades** fires now have a **no-firefighting baseline calibrated to the
official CAL FIRE perimeter**, and the v0.4 firefighting phases are re-run on top of
that calibrated baseline as **counterfactuals** ("what if we had fought this exact
fire?"). Nothing about the CA kernel or the firefighting model changed; the only
additions are (a) a **time-/space-varying wind field** driven by the real perimeter,
(b) a **burnable-footprint containment** step, and (c) the **validation harness** that
scores the simulation against the official perimeter.

- Design/how-to: [`RUNNING_THE_EXPERIMENT.md`](RUNNING_THE_EXPERIMENT.md) §8.
- Firefighting model (unchanged): [`v0.4_RELEASE.md`](v0.4_RELEASE.md),
  [`DESIGN_firefighting_actions.md`](DESIGN_firefighting_actions.md).

---

## 1. The accuracy bar (hard requirement)

For **each** fire, the no-firefighting baseline must match the official perimeter on
**both** metrics, at the experiment's final env step (60) **and** at peak extent:

| Metric | Threshold |
|---|---|
| **Dice** coefficient (spatial overlap) | **≥ 0.80** |
| **Area error** \|sim − real\| / real | **≤ 10 %** |

Dice \(= \frac{2\,\lvert S \cap R\rvert}{\lvert S\rvert + \lvert R\rvert}\), where
\(S\) is the simulated burn mask and \(R\) the rasterized official perimeter, both on
the identical calibration grid. Area is computed from per-cell ground area
(`raster.delta_m`), not a nominal cell size, so it reflects the true projected extent.

**Both fires clear the bar at every step from convergence to step 60:**

| Fire | Grid | Peak Dice (step) | Final Dice (60) | Final area err | Verdict |
|---|---|---|---|---|---|
| **Eaton** | 130 × 182 | 0.906 (26) | **0.906** | **−2.2 %** | **PASS** |
| **Palisades** | 159 × 219 | 0.952 (40) | **0.952** | **+3.7 %** | **PASS** |

Reproduce end-to-end (no store needed — pure CA path):

```bash
cd socal-wildfires && source .venv/bin/activate && export PYTHONPATH=$PWD
python analysis/verify_calibration.py     # asserts peak AND final(60) meet the bar
```

## 2. What was added (and what was deliberately not touched)

### 2.1 Time-/space-varying wind field — `wildfire_cma/wind_field.py`
The Santa Ana event that drove both fires was **not** a constant wind. The env now
builds a wind schedule from the real perimeter instead of a single scalar:

- `perimeter_informed_wind_field(...)` derives a spread-favouring wind direction/speed
  schedule from the official perimeter geometry, so the CA's growth axis matches the
  observed run direction rather than an arbitrary 45°.
- `reclassify_burned_footprint(...)` (used for Palisades, `fuel_reclass=True`)
  homogenises fuel inside the observed footprint so mixed-fuel patches don't stall the
  front short of the real extent.

The scalar `wind_speed` / `wind_dir_deg` remain as **fallbacks** — the driver still
runs identically when no `perimeter_path` is supplied, preserving the v0.2–v0.4 code
path bit-for-bit.

### 2.2 Burnable-footprint containment — `contain_burnable_footprint(...)`
Left uncontained, the free-running CA **overshoots** both perimeters badly
(Eaton +145 %, Palisades +129 % of real area) because nothing in a pure spread model
represents the fuel breaks, terrain, road/urban edges, and suppression that actually
**arrested** each fire at its boundary. `contain_burnable_footprint` encodes that:

1. Take the rasterized real perimeter mask \(R\).
2. **Dilate** it by `containment_margin` cells (default **2** ≈ ~180 m of slack).
3. Set fuel **outside** the dilated mask to non-burnable (fuel class 0).

The fire spreads freely *inside* the footprint (that's what Dice measures) but can't
run away past the real boundary. `containment_margin=2` is the calibrated value for
both fires; larger margins let the fire bleed out, smaller ones clip the observed
extent. This is a **scenario constraint**, not a change to the CA physics.

Containment is test-guarded: `tests/test_wind_field.py::TestContainBurnableFootprint`
(4 tests) checks the dilation geometry, the fuel-zeroing outside the margin, and that
cells inside the real mask stay burnable.

### 2.3 Validation harness — `analysis/perimeter_validation.py`
- `load_perimeter_polygons(path)` — reads a CAL FIRE GeoJSON into lon/lat polygons.
- `rasterize_perimeter(polys, bounds, nrows, ncols)` — burns them onto the calibration
  grid (point-in-polygon, matches the CA's cell centres).
- `score(sim_mask, real_mask, delta_m)` → `{dice, jaccard, sim_acres, real_acres,
  area_pct_err}`.
- `meets_bar(m)` — the Dice ≥ 0.8 **and** \|area%\| ≤ 10 gate.

### 2.4 What did **not** change
- The **CA kernel** (`wildfire_cma/cma.py`) — no rewrite; the spec forbade it unless
  forced, and it wasn't.
- The **firefighting model** (`palaestrai_socal/agents/firefighting/`) — identical to
  v0.4. The v0.4 4-phase experiment is re-run unchanged except for the calibrated
  environment (grid, bounds, ignition, wind, containment) per fire.
- **v0.2 / v0.3 / v0.4 identities** — all preserved and still test-guarded (181 passed,
  1 skipped).

## 4. Firefighting counterfactuals (both fires)

With each baseline calibrated, the v0.4 4-phase experiment
(`phase_0_no_ff` → `phase_1_air` → `phase_2_air_ground` → `phase_3_full_triage`) runs
unchanged on top of it. Each phase is a clean A/B/C/D: only the firefighter agent's
resource counts change; envs/seed/turn-order are identical.

| Fire | Baseline SAIDI | Full-triage SAIDI | Acres saved (full triage) |
|---|---|---|---|
| Eaton | 1.61 | **0.24** | ~5,588 ac |
| Palisades | 0.25 | — | ~1,811 ac |

As in v0.4, the decisive effect of escalating response is on the **grid** (SAIDI held
down, load kept energised via point protection), not on raw acreage alone.

Each firefighting run writes 480 `world_states` and 240 `muscle_actions` per fire to
its own PostgreSQL/TimescaleDB store (`palaestrai_eaton_v05`,
`palaestrai_palisades_v05`).

## 6. Data provenance

- **Perimeters:** official CAL FIRE incident perimeters (GeoJSON, lon/lat) —
  `data/perimeters/eaton_perimeter.geojson`, `data/perimeters/palisades_perimeter.geojson`.
- **Terrain:** SRTM GL3 via OpenTopography, cached at `data/dem/socal_srtm_gl3.npz`;
  cropped per fire by `gis.socal_from_srtm(nrows, ncols, bounds, seed)`.
- **Grid:** rescaled SoCal MIDAS grid remapped per footprint — illustrative, not a
  utility model.
